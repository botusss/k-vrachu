1. Запуск и остановка

Перейдите на страницу расписания нужного врача.

В правом нижнем углу появится тёмная панель управления «🤖 Помощник записи».
Нажмите зеленую кнопку «🚀 Начать поиск» — бот начнет проверку и обновление страницы.

Для остановки в любой момент нажмите красную кнопку «⏸️ Стоп».

2. Настройка временных интервалов
В поле «Интервалы (чч:мм)» вы можете задавать рамки поиска:

Пустое поле (по умолчанию) — забирает ближайший свободный талон на любое время.

Точное время с минутами: 10:30-12:15

Несколько интервалов через запятую: 08:00-11:30, 14:15-16:45

Простой формат по часам (тоже работает): 10-12

Примечание: Если вы указали интервал (например, 10:30-12:15), но в нем нет талонов, бот выведет предупреждение в лог и возьмет ближайший доступный очный талон, чтобы не упустить запись.
